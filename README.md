# Portfolio — Next.js

Erfan Morshedzadeh portfolio (Next.js App Router + MUI + Motion). Deployed for Vercel.

## Scripts

```bash
npm run dev      # local development
npm run build    # production build
npm run start    # serve production build
npm run lint     # oxlint
```

## Routes

- `/` — welcome / portfolio
- `/resume` — in-app resume viewer
- `/resume-file` — PDF stream (Route Handler)
- `/jobs` — jobs list

## Deploy

Connect the repo to [Vercel](https://vercel.com). Framework preset: Next.js.
